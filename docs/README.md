# Documentation SmartRecruit

Ce dossier contient la documentation detaillee du projet. Le point d'entree rapide reste le [README racine](../README.md).

## Documents

- [SmartRecruit_Documentation_Complete.tex](SmartRecruit_Documentation_Complete.tex): documentation technique principale sur l'architecture, les dossiers, les fichiers, le pipeline, le scoring et les composants backend/frontend.
- [LATEX_COMPILATION_GUIDE.md](LATEX_COMPILATION_GUIDE.md): guide court pour produire un PDF a partir du document LaTeX.
- [code_comments_report.md](code_comments_report.md): synthese des commentaires de code et des roles de fichiers.
- [documentation_audit.md](documentation_audit.md): etat de la documentation, configuration de reference et commandes documentees.

## Organisation

Le README racine contient les informations utiles au demarrage: objectif, flux global, installation, configuration, lancement et tests. Le document LaTeX contient les details fichier par fichier. Les commentaires de code documentent les choix et limites directement au niveau des modules concernes.

## Maintenance

Quand le code change:

1. Mettre a jour le README racine pour les commandes, prerequis et limites utiles au demarrage.
2. Garder les details fichier par fichier dans le LaTeX ou dans les commentaires de code.
3. Verifier les commandes documentees avant de les presenter comme valides.
